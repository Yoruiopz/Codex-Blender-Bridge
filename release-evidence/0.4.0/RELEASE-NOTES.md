Blender Codex Bridge **0.4.0 alpha** adds bounded artist plans, protected scope and target verification, quaternion transforms, modeling/UV/paint tools, weight and animation foundations, cooperative jobs, and approved-path GLB/FBX export foundations. It contains **266 MCP tools**. Capabilities retain their documented ownership and context limits.

This is a development prerelease. **The full artist-workflow 1.0 target is incomplete; all fourteen stable requirements remain open. Windows compatibility work and testing are deferred and unverified.** No merge into `main` is part of this release.

Validated source: [`4470d88bb4d8fb1ed75e86090dd6886fb55eb589`](https://github.com/Yoruiopz/Codex-Blender-Bridge/commit/4470d88bb4d8fb1ed75e86090dd6886fb55eb589), tree `0353d119fd44ac918dc66d871ef2279576f9312d`.

- [Exact-commit CI](https://github.com/Yoruiopz/Codex-Blender-Bridge/actions/runs/40058140088): seven jobs passed; each Python 3.10–3.12 × MCP SDK 2.0.0/2.2.0 cell passed **7,582 tests**, with three Windows-only skips. Lint, typing, tool inventory and package checks passed.
- Selected isolated Linux Blender **4.5.14 LTS** (`62c1db4208e8`) and **5.2.2 LTS** (`d13f752e3b9c`) cases passed: UV boundary prerequisites, weight operations, and fresh-process GLB/FBX fixture export/reimport. These checks do not establish a public UV Edit Mode guard, complete delivery content/materials, visual quality, native undo or full workflow acceptance.
- The exact packaged add-on passed a bounded fresh-candidate → published 0.3.0 → upgrade → rollback probe in one process on each Linux build, including loopback reconnect and default permission denial. Blender restart, preferences migration and installed artist scenarios A–F remain unverified.

This was registration/validation coverage, not MCP-to-Blender workflow acceptance.

**Important restrictions:** `project.save` remains unavailable for Save and Save As; protected capture and shader-interface REMOVE/conversion remain unsupported; typed asset import remains quarantined on the known Blender 5.2.2 build. Arbitrary Python stays disabled by default. Neither retained buffers nor global undo history provide durable backups. Native full-inventory, reviewed appearance, constrained-memory and complete A–F acceptance remain outstanding. The declared Blender 4.2 minimum is metadata, not qualification of every patch or platform.

Install the attached add-on ZIP without extracting it, install the matching MCP wheel, and update the optional Codex plugin together. Restart Blender and the MCP client, recreate session references/previews/baselines, and start with inspection. Use disposable scenes or project copies and retain normal backups. A software rollback does not undo scene edits or exported files.
