# Blender Codex Bridge 0.6.0 — prospective alpha

**Unqualified development source; not published.** Matching numeric component
versions are prepared at 0.6.0 with the Alpha classifier. This preparation updates
release status and preserves the 266-tool public surface. Private prerequisites
now include an immutable bounded static GLB reconstruction plan and an isolated
geometry-preview experiment; neither is a new public workflow tool. The integrated
prerequisite source at `9289069` passed 8,124 tests with three Windows-only skips
and static checks. This is not native, installed or release acceptance.
Curve, cloth-job and material-recovery work remain separate lanes. Custom-API
work is stopped outside this candidate; its source findings remain historical.

Install the [published 0.5.0 alpha](0.5.0.md) using its matching assets and checksums.
Its exact-source results do not qualify this source. Protocol 1.0, Blender's declared
4.2.0 minimum and standalone Python 3.10+ remain unchanged; those declarations are
not broad platform qualification.

All [29 implementation items](../implementation-completion.md) and
[14 open release gates](../release-1.0-readiness.md) remain mandatory. Windows
compatibility/testing remains deferred and unverified. Safe save, protected
capture, shader-interface REMOVE and exact-build 5.2 typed-import holds remain.
The architecture uses **official, unmodified Blender only**: no fork, custom
build or distribution. The [native witness finding](../release-1.0-readiness.md#current-native-witness-blocker)
limits the older strict same-Main/raw pending-Base guarantee, not ordinary
unarmed capture. Stock redesign options are explicit synchronization with
declared mutation semantics or a separate Scene/process snapshot preview.
Protected capture remains refused until a new profile qualifies matched parent
authored-data/context preservation, without clearing or rebasing armed protection
or restoring over manual edits. GPU drawing/context getters do not imply passive
evaluation, and an explicit ViewLayer update is an authorized mutation. Safe-save
catalog effects remain a separate unchanged requirement.

The selected geometry-preview experiment passed before integration at `ea1da49`
on official Linux Blender 4.5.14 and 5.2.2. Both fresh workers reconstructed and
rendered the admitted geometry; independent measured writer projections and plan
metadata remained unchanged, and both images were reviewed. Its geometry-only
profile omits source materials and current viewport appearance. A production
permission, job, cancellation, stale-source and publication contract remains
required; see [the experiment and its limits](../stock-isolated-asset-preview-research.md).

A meaningful later 0.6.0 prerelease requires completed reviewed functionality,
focused/full validation, exact-source CI and matching package/native/installed
checks. A version increment alone is not a release milestone.
