## New behavior

`preview.geometry_start` captures a bounded named authored Mesh and starts a
fixed separate official Blender worker. Poll `jobs.inspect`, then retrieve the
successful PNG with `preview.geometry_image`. Blender requires INSPECT_SCENE,
CAPTURE_VIEWPORT and ACCESS_EXTERNAL_FILES. The worker never opens the artist's
project. It creates its own scene, fixed framing, a new opaque material and a
transparent background.

The initial profile is 128 × 128, eight samples and one CPU thread, with at most
512 vertices, 1,024 edges, 512 faces and 2,048 corners. It admits only the exact
Linux Blender **4.5.14** (`62c1db4208e8`) and **5.2.2** (`d13f752e3b9c`) builds.
Targets are local, unshared static Object-mode meshes with XYZ rotation, default
delta transforms and no parent, modifiers, constraints, animation or shape keys.
See [geometry preview limits](../geometry-preview.md).

Images are temporary session handles. Source or plan changes, lost permissions,
cancellation, stop, disconnect and expiry prevent delivery. Owned workers are
terminated/reaped before their known private files are removed. Unknown cleanup
retains effects and refuses publication; these handles and files are not backups.

If operation-history recording raises, the executor attempts it once and reports
unknown history outcome. A serializable primary denial survives a secondary
history failure. Failed outcome reporting returns a bounded SERVER_ERROR with
possible mutation and required reinspection. A missing linked receipt marks the
artist-step journal incomplete. These errors do not prove rollback or authorize
an automatic retry.

## Verified evidence

The following results apply to the exact released source and accepted package
bytes. Later curve, direct-weight, material-recovery, cloth, native-save and private
GLB development is excluded from this release's claims.

- [Exact-commit CI](https://github.com/Yoruiopz/Codex-Blender-Bridge/actions/runs/40196147205)
  passed all seven jobs. Each Python 3.10–3.12 × MCP SDK 2.0.0/2.2.0 cell passed
  **8,403 tests**, with the same three Windows-only skips. Ruff, mypy, generated
  inventory and whitespace checks passed.
- The three installers and installer checksums passed API size/digest checks,
  archive/member safety checks, immutable Git comparisons and wheel RECORD
  verification. The release uses these exact CI-built installer bytes.
- **Eight selected interactive source processes** passed: registered geometry
  preview, executor-history containment, paint jobs and the shared Scene-job
  kernel, each on both exact Linux builds. Geometry cases included success, stale
  fetch, permission denial, cancellation before worker launch and running-worker
  permission revocation. Independent declared source projections preserved dirty
  unrelated animation and pending hidden selection. Actual plan enforcement used
  a **null protected-data baseline**; a populated baseline remains unqualified.
- **Four installed background processes** covered two upgrade/rollback routes,
  from published 0.3.0 and 0.5.0, on both builds. Each process made four phase
  observations: fresh candidate installation, previous-package replacement,
  upgrade and rollback, for **16 installed phase observations**. Eight candidate
  previews used installed start/inspect/image methods, with default external-file
  denial followed by explicit local consent. Installed module/worker bytes
  matched the ZIP, real worker paths contained spaces and workers were reaped.
  Each route remained in one fresh process; process restart and preference
  migration are not established.
- A new wheel installation and fresh MCP SDK 2.2.0 stdio session exposed
  **268 tools**, with 25 disabled domains, **240 SDK receipts** and **210 malformed
  standard-JSON cases**. Installed bridge and RECORD bytes matched the wheel and
  accepted Git source. Third-party dependencies used 59 explicit read-only links
  to an existing dependency environment; the bridge installation and session were
  new, and the dependency environment remained unchanged.
- **Ten reviewed geometry images** passed framing and silhouette review: two
  source-fixture triangles and eight installed cube previews. This is structural
  geometry evidence, with no original-material or artistic-quality acceptance.
- After publication, **all six assets** were downloaded anonymously and their
  sizes and SHA256 hashes matched the accepted files and API digests. Installer
  and evidence checksums were verified separately.

The curated evidence archive retains CI artifacts/logs, native reports,
installation receipts, source/package hashes, reviewed images and a standalone

## Remaining limits

These selected Linux checks do not qualify the complete native inventory,
installed MCP-to-Blender scenarios A–F, constrained-memory operation, native
undo, durable recovery or stable 1.0. Windows compatibility/testing is deferred.

The preview omits original materials, UVs/attributes, evaluated modifiers,
children, instances and current viewport appearance. Matching images and
declared projections do not prove whole-Main hidden preservation, provider purity
or complete protected-data coverage. Individual native blocking intervals and
parent peak memory remain unmeasured. Worker RSS is a whole-process peak, not an
operation delta; no universal realtime or preemption guarantee is claimed.

Existing restrictions on `project.save`, protected `viewport.capture`,
shader-interface REMOVE/conversion, the held Timeline/provider reproduction and
the exact Blender 5.2.2 typed importer remain. Historical
[0.5.0 4K evidence](0.5.0.md#verified-evidence) stays specific to its source.
Main and draft PR #8 were not merged for this release. Protocol 1.0, the declared
Blender 4.2 minimum and standalone Python 3.10+ remain unchanged; those declarations
are not broad platform qualification or stable 1.0 acceptance.
