# Blender Codex Bridge 0.6.0 — prospective alpha

**0.6.0 alpha candidate.** Matching component versions are 0.6.0
with the Alpha classifier. The public surface has 268 typed tools. Install the
[published 0.5.0 alpha](0.5.0.md) until matching accepted 0.6.0 assets are available.

This increment adds an official-Blender geometry preview workflow and contains
history/reporting failures without repeating an operation. It does not complete
the full artist workflow. All [29 implementation items](../implementation-completion.md)
and [14 stable release requirements](../release-1.0-readiness.md) remain mandatory
and open. Windows compatibility and testing remain deferred and unverified.

## New behavior

`preview.geometry_start` captures a bounded named authored Mesh and starts a
fixed separate official Blender worker. Poll `jobs.inspect`, then retrieve the
successful PNG with `preview.geometry_image`. Blender requires INSPECT_SCENE,
CAPTURE_VIEWPORT and ACCESS_EXTERNAL_FILES. The worker uses its own scene,
fixed framing and a new opaque material; it never opens the artist's project.

Images are temporary session handles. Source or plan changes, lost permissions,
cancellation, stop, disconnect and expiry prevent delivery. Owned worker processes
are terminated/reaped and their known private files cleaned; unknown cleanup
retains evidence and refuses publication. The fixed 128px/eight-sample profile
admits only the exact Linux 4.5.14 and 5.2.2 builds and bounded static local meshes.
See [geometry preview limits](../geometry-preview.md).

If operation-history recording raises, the executor attempts it once and reports
a structured error with unknown history outcome. A serializable primary denial
survives a secondary history failure. If outcome reporting itself fails, a bounded
SERVER_ERROR reports possible mutation and required reinspection. Missing linked
operation receipts mark the existing artist-step journal incomplete. These errors
are not proof of rollback or permission to retry the mutation.

## Remaining candidate checks and limits

Candidate qualification requires integrated full checks, exact-commit CI, matching package audit, fresh wheel
and add-on installation, installed preview execution, upgrade/rollback, checksums,
retained evidence and anonymous download verification before publication. Consult
the published release's exact-source evidence for the accepted candidate results. Prior releases and their assets remain available and unchanged.

The preview omits original materials, UVs/attributes, evaluated modifiers, children,
instances and current viewport appearance. Whole-Main hidden preservation,
permission-provider purity, a populated protected baseline, individual native
blocking intervals, parent peak memory and constrained-memory acceptance remain
unqualified. Measured worker RSS is a process peak, not an operation delta.

Safe save, old protected viewport capture, shader-interface REMOVE and exact-build
5.2 typed-import holds remain. Curve, cloth and material-recovery work stays outside
this candidate. No custom Blender build, fork or distribution is required. Protocol
1.0, declared Blender 4.2 minimum and standalone Python 3.10+ remain unchanged;
those declarations are not broad platform qualification or stable 1.0 acceptance.
