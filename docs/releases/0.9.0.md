## Finite increment

The typed `project.native_save_preview` / `project.native_save_start` workflow
retains canonical queued admission, exact source/path/overwrite/loss intent,
bounded jobs and a distinct expiring **Native Save Effects** grant armed locally
in Blender. Inspect Scene, Save Project and Access External Files remain required;
the MCP client cannot arm consent or change the approved project folder.

The declared profile admits an existing empty native `SequenceEditor` with its
ordered public channels. It preserves arbitrary channel names, lock/mute flags
and the public 5.2 channel number. On 4.5 the hidden stored channel index remains
unobserved. Strips, caches, broader sequencer state and rigid-body worlds remain
outside this profile; an artist must not clear project data to force admission.

Already-loaded, unanimated, packed, clean RGBA FILE images share a finite
**16,777,216-pixel / 80 MiB packed-byte aggregate budget**, with at most four
images and each dimension at most 4,096. Native files remain capped at **256 MiB**
for complete streamed hashing and fresh-process reopen. Above the legacy
1,048,576-pixel threshold, fresh Linux observations require **8 GiB available
memory and 2 GiB free disk** at the documented allocation/open/decode gates.
Unknown or insufficient observations refuse; these are admission checks, not
reservations or hard process limits. Complete packed-byte and raw Float32 pixel
digests, including alpha, remain part of the comparison.

The other finite Scene/Object/mesh/rig/Action/material limits remain in the
[native-save contract](../native-project-saving.md). Copy New publishes verified
owned staging without clobbering. Save Current and Save As retain explicit
`NATIVE_DESTINATION_RACE_NOT_EXCLUDED` acceptance. Native callbacks/catalog
effects and already-written files cannot be rolled back by cancellation or undo;
known artifacts and unknown effects remain visible on terminal results.

## Held features and full target

Legacy `project.save`, protected viewport capture, shader REMOVE/conversion,
the Timeline/provider reproduction and existing exact-build import quarantines
remain held. Arbitrary Python stays disabled by default; permissions, literal
loopback transport and main-thread execution remain unchanged.

Paired original/snapshot 4K raw-EXR sizing, 640 MiB packed / 1 GiB saved-file work,
source recovery, current-pixel controllers/lifecycle, dirty/generated conversion,
broader material/GLB/cache workflows and private cloth tools are excluded.
Clean-file save evidence does not qualify edited sRGB pixels or complete durable
backup. No new tool names or broader artist-delivery claim follow from this release.

**All 29 implementation items and all 14 stable-release gates remain OPEN.**
The [0.9 blocker plan](0.9.0-blocker-plan.md) retains the complete artist-workflow
target and concrete next validation steps. **Windows compatibility and testing
remain deferred and unverified** until implementation completion; the later
Windows 11 / Blender 4.5 LTS and stable 5.x installed acceptance matrix is still
mandatory. This alpha does not establish cross-platform support or stable 1.0.
Main, draft PR #8, previous releases and repository visibility remain unchanged.
